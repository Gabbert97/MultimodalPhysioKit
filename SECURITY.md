# Security Policy

## Supported versions

Only the latest released version of MultimodalPhysioKit receives security
updates. Older releases are not supported.

## Reporting a vulnerability

Please report security vulnerabilities privately through
[GitHub Private Vulnerability Reporting](https://github.com/Gabbert97/MultimodalPhysioKit/security/advisories/new)
when it is enabled.

Do not open a public issue for vulnerabilities that could expose sensitive
data or credentials, enable arbitrary code execution, or exploit a dependency.
If private vulnerability reporting is unavailable, contact the repository
owner through the contact method published on the
[owner's GitHub profile](https://github.com/Gabbert97).

Include a concise description, affected version, reproduction steps, and the
potential impact. Avoid including real physiological recordings or other
sensitive data.
