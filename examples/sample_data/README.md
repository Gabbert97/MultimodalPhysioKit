# Bundled synthetic fixture

This directory contains:

```text
synthetic_multimodal_180s.hdf5
```

The fixture contains no human measurements. Every sample in every channel is
mathematically generated by
[`tools/generate_synthetic_sample.py`](../../tools/generate_synthetic_sample.py),
which is the canonical source for the HDF5 file.

The fixture exists only to demonstrate and test the supported
BioSignalsPlux/OpenSignals HDF5 reader, signal conversion, temporal phases,
plotting, and modality processors. It is not clinical data, a scientific
validation dataset, or intended to represent scientifically validated human
physiology.

## Generation parameters

- Duration: 180 seconds
- Sampling frequency: 100 Hz
- Samples per channel: 18,000
- ADC resolution: 16 bits
- NumPy random seed: 20260808
- Channels: ECG, EDA, RIP respiration, temperature, fNIRS red, and fNIRS
  infrared
- Generator: `MultimodalPhysioKit synthetic sample generator v1`
- Data license: CC0-1.0, as recorded in the HDF5 metadata

The ECG contains deterministic synthetic beats near 72 beats per minute with
modest rate variability. EDA contains a tonic component and modeled phasic
responses. Respiration, temperature, and fNIRS contain smooth deterministic
trends and oscillations with small seeded noise. These constructions are
chosen to exercise software paths, not to model a population or experimental
protocol.

The public reader exposes these signal names:

```text
ecg
eda
rip
temp
fnirs_red
fnirs_infrared
```

## Regeneration and verification

From the repository root, using an environment with the Python package
dependencies installed, regenerate the tracked fixture with:

```bash
python tools/generate_synthetic_sample.py
```

Verify that the tracked fixture logically matches a fresh deterministic
generation with:

```bash
python tools/generate_synthetic_sample.py --check
```

The generator fails if a physical signal cannot be represented by the 16-bit
ADC conversion. It also reads the generated file through the public Python
BioSignalsPlux reader and checks channel names, units, sampling frequency,
length, metadata privacy, and physical-value round trips.
